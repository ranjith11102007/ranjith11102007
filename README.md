## 🚀 Featured Projects

### [Care-AI](https://github.com/ranjith11102007/Care-AI) — AI mental health & crisis support 🧠

A support system for remote communities with CBT-based chat, mood tracking and a low-bandwidth mode.

- **Stack:** TypeScript · React · Vite · Firebase · Vercel AI SDK
- **Focus:** accessible, low-bandwidth mental-health support with practical AI assistance
- 🔗 [Repository](https://github.com/ranjith11102007/Care-AI) · [Live demo](https://care-ai-three.vercel.app)

### [FormLink (FarmLink)](https://github.com/ranjith11102007/FormLink) — Farmers-to-customers marketplace 🌾

A marketplace connecting local farmers directly with customers, with product listings, cart, orders, delivery OTP and an admin panel.

- **Stack:** Python · Flask · SQLite · Jinja2 · Razorpay
- **Focus:** a complete order flow from listing to delivery, including payments
- 🔗 [Repository](https://github.com/ranjith11102007/FormLink) · [Live demo](https://form-link-omega.vercel.app)

### [LEARNOFFLINE](https://github.com/ranjith11102007/LEARNOFFLINE) — Offline-first learning PWA 📚

A learning app built for low-connectivity regions — download lessons, take quizzes offline, and sync when you're back online.

- **Stack:** HTML · CSS · JavaScript · IndexedDB · Service Workers
- **Focus:** resilient learning that keeps working without a reliable connection
- 🔗 [Repository](https://github.com/ranjith11102007/LEARNOFFLINE)

### [Mini-Runner](https://github.com/ranjith11102007/Mini-Runner) — Endless runner game 🎮

A fast-paced browser game with dynamic obstacle dodging, power-ups and score tracking.

- **Stack:** HTML · CSS · JavaScript
- **Focus:** responsive browser gameplay with clean vanilla JavaScript
- 🔗 [Repository](https://github.com/ranjith11102007/Mini-Runner)
